# Sobre o Projeto

O **Android Mobile Project** foi desenvolvido como projeto de estudo para a plataforma Android, aplicando conceitos de desenvolvimento mobile, organização de telas, componentes de interface e gerenciamento do ciclo de vida de aplicações.

O projeto demonstra a criação de uma aplicação utilizando as ferramentas oficiais do ecossistema Android.

---

# Funcionalidades

- Interface gráfica para dispositivos Android
- Navegação entre telas
- Manipulação de componentes da interface
- Organização da aplicação em atividades
- Estrutura preparada para expansão de funcionalidades

---

# Tecnologias Utilizadas

- Android Studio
- Java
- Android SDK
- XML
- Gradle

---

# Arquitetura

O projeto segue a arquitetura padrão de aplicações Android.

### Activities

Responsáveis pelo gerenciamento das telas da aplicação.

### Layouts

Definem a interface gráfica utilizando arquivos XML.

### Resources

Contêm recursos utilizados pela aplicação, como imagens, textos, cores e estilos.

### Manifest

Responsável pela configuração da aplicação Android.

# Como Executar

## 1. Clone o repositório

```bash
git clone https://github.com/gabrielafonsods/android-mobile-project.git
```

## 2. Abra o projeto

Abra o projeto utilizando o **Android Studio**.

## 3. Aguarde a sincronização

O Android Studio fará o download automático das dependências do Gradle.

## 4. Execute a aplicação

Selecione um emulador Android ou um dispositivo físico conectado e execute o projeto.
